# Demo and localization checklist

- Use real exported components. Give Alert, Dialog, Toast, and loading previews an explicit trigger. Keep Breadcrumbs and Pagination examples in local state, preserving focus and URL. Use actual shared controls for settings.
- Keep executable previews and copyable code synchronized. Reuse the same source for larger recipes.
- English is the source copy. Update Korean, Japanese, and Simplified Chinese visible text and accessible labels together. Keep API names, event names, and executable examples stable. Verify language reload and 320 px layout in all four locales.
- Keep public README copy focused on the product. Update light and dark captures across localized READMEs if the public visuals change materially.
