# Vertactics phase delivery

Read PROMPT, SPEC, and AGENTS.md in the current checkout. Identify the smallest coherent unfinished requirement and start from the repository's approved branch base.

- Scope the change to the corresponding SPEC IDs. Preserve user edits. Use the normal application entry and the affected project checks.
- Mark individual requirements verified only when the relevant evidence exists. Record commands, results, and blockers. Keep partial issues open and continue independent work when possible.
- Report the PR, SPEC IDs, and exact-head CI status. Follow the repository workflow and the authorization for the task. Merge or deploy only when authorized.
