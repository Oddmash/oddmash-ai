# Oddmash brand design

Read the product's visual baseline. For interfaces using Oddmash UI, inspect the shared tokens and the product's semantic overrides. Follow an explicitly documented product identity when its visual system differs.

- Where the Oddmash ribbon is part of the product identity, use paired diagonals and adjoining planes to mark a boundary, direction, or grouping. Give the motif a legible role and keep the working interface dominant.
- Use contrast and hierarchy before extra ornament. In the shared neutral palette, reserve blue for focus and red for errors. Preserve meaningful product-specific colors and encode states in more than one visual channel where needed.
- Choose display, body, UI, and code faces by role. Geist Sans and Geist Mono are useful starting points in the shared system. Check actual glyph coverage, mixed-script line breaks, fallback, transfer size, and the license before committing font assets.
- Compare real renders at narrow and desktop widths, including long labels and visible focus. Keep product-specific styling in the consumer. Promote an abstraction into Oddmash UI once more than one product demonstrates the same stable need.
